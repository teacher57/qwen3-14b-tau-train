# Augmentation datasets and conversations
- `teacher32b_passed_sft_lookups_confirm.json`: the 178 augmented SFT conversations (every order opened, every change confirmed); statistics in the `*_stats.json` file.
- `habit_dataset.json`: habit-only dataset (898 conversations; `supervise` lists the trained turns). Built, not trained.
- `retail_aug_4trials_results.jsonl` / `retail_aug_4trials_transcripts.jsonl`: all 460 τ-bench retail test conversations of the augmented model (115 tasks x 4 trials).
